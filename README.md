**What I'm building**

[**Sahayak**](https://github.com/VelvetDragon/sahayak) &nbsp; Multi agent AI data analyst. Ask a dataset a question in plain English; a planner, executor, and verifier write and run the SQL and Python, then check their own answer before returning it.

[**DriftGuard**](https://github.com/VelvetDragon/driftguard) &nbsp; ML drift monitoring with automatic retraining. Watches a live model for data and performance drift, retrains when it genuinely degrades, and promotes the challenger only when it beats the champion.

[**AeroPulse**](https://github.com/VelvetDragon/aeropulse) &nbsp; Real time flight analytics. Live OpenSky data flows through a dbt medallion lakehouse on DuckDB into an anomaly model and a Streamlit dashboard.
